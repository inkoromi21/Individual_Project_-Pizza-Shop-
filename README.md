# Индивидуальный проект: Магазин пиццы (Factory Method)

## 📌 Аннотация

Небольшая пиццерия принимает заказы на разные виды пиццы. Клиент выбирает тип из меню, а система должна **создать нужную пиццу** и провести её через стандартные этапы приготовления (подготовка, выпечка, нарезка, упаковка).

Консольное приложение решает прикладную задачу: **оформить заказ без жёсткой привязки клиентского кода к конкретным классам пицц**. Для этого используется порождающий паттерн **Factory Method (Фабричный метод)**.

## 🎯 Цель проекта

- Реализовать консольный заказ пиццы разных типов.
- Применить паттерн **Factory Method** для создания объектов `Pizza`.
- Показать, как расширять систему новыми видами пицц без изменения общего алгоритма заказа.

## 🧩 Паттерн Factory Method — зачем он здесь

**Проблема:** если создавать пиццы через `new MargheritaPizza()` / `new PepperoniPizza()` прямо в `Program`, клиентский код начинает зависеть от всех конкретных классов. При добавлении нового вида придётся править меню, заказ и, возможно, другие места.

**Решение:** вынести создание в иерархию «создателей»:

| Роль в паттерне | Класс в проекте |
|-----------------|-----------------|
| Product | `Pizza` и наследники (`MargheritaPizza`, `PepperoniPizza`, `HawaiianPizza`) |
| Creator | `PizzaStore` (абстрактный) |
| Concrete Creator | `SimplePizzaStore` |
| Factory Method | `CreatePizza(PizzaType type)` |
| Template Method | `OrderPizza(PizzaType type)` — общий сценарий заказа |

`OrderPizza` знает **как** готовить любую пиццу, а `CreatePizza` решает **какую именно** создать. Клиент (`Program`) работает только с `PizzaStore`, не зная деталей конкретных классов.

Это поддерживает **принцип открытости/закрытости (OCP)**: новый вид пиццы добавляется в `SimplePizzaStore.CreatePizza` и в меню, без переписывания `OrderPizza`.

## 📁 Структура проекта

```
Pizza-Shop/
  Pizza-Shop/
    Program.cs              — точка входа, цикл меню
    ConsoleUI/              — ввод и отображение меню
    Pizzas/                 — продукты (базовая и конкретные пиццы)
    Stores/                 — создатели (PizzaStore, SimplePizzaStore)
```

## ▶️ Как запустить

1. Открыть решение `Pizza-Shop/Pizza-Shop.slnx` в Visual Studio (или проект `Pizza-Shop/Pizza-Shop/Pizza-Shop.csproj`).
2. Собрать и запустить проект (F5 / Ctrl+F5).
3. В консоли выбрать действие:
   - `1` — заказать пиццу;
   - `2` — показать меню;
   - `0` — выход.

## 🧪 Примеры сценариев

1. **Заказ Маргариты:** `1` → `1` → в консоли этапы приготовления и «Готово!».
2. **Просмотр меню:** `2` → список пицц.
3. **Неверный номер пиццы:** `1` → `9` → сообщение «Такой пиццы нет в меню».
4. **Выход:** `0`.
